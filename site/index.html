Engineering Discipline

Honest trade-offs: what Quarry is and isn't

By omitting enterprise migration suites, visual query builders, and heavyweight background daemons, Quarry delivers sub-second startup times and deterministic memory footprints.

What Quarry Focuses On
  • ✓
    Instant native startup: Compiled in Rust with native windowing. Launches in fractions of a second.
  • ✓
    GPU-rendered results grid: Smooth scrolling through large results, with instant cell aggregates (sum, min, max, average).
  • ✓
    Safety guardrails: Guarded production connections, SSH tunnel support, and explicit SQL staging review before commits.
  • ✓
    Zero telemetry or cloud accounts: 100% local client under GPL-3.0 with system keychain password management.
What Quarry Is Not
  • ✗
    Not a drag-and-drop query generator: Designed for practitioners who write SQL directly and value schema-aware autocomplete.
  • ✗
    Not an ETL or database migration framework: Does not attempt to replace Flyway, Liquibase, or dedicated schema diffing pipelines.
  • ✗
    Not an Electron or Java app: Eliminates high idle memory overhead and background indexing churn.
  • ✗
    No cloud sync or vendor lock-in: Connections and preferences live locally on your workstation.
